# Mock Paper Generation Notes

Use this file only as a compact reminder, not as the full rule source.

## Core objective
- Generate original Chinese public-service aptitude questions that feel like real exam items, not training placeholders.
- Keep the difficulty near the middle band.
- Each question should test exactly one core point.

## Required quality bar
- No placeholder stems, options, answers, or explanations.
- No repeated stems with only numbering changed.
- No fake law/article titles or fabricated source URLs.
- Wrong options must be same-domain, same-level, and plausibly tempting.
- Explanations must be specific and usable.

## Module reminders
- Political / common sense: factual, concrete, no pseudo-authority tone.
- Verbal: context first, options compete on wording and logic, not obvious completeness.
- Quantitative: clean data, valid arithmetic, one solvable correct answer.
- Judgment / reasoning: one logic core per item, no double-correct answers.
- Data analysis: one shared material block must support the whole group.

## Explanation format
- Tested point
- Decisive basis
- Why the answer is correct
- Why at least one distractor fails
